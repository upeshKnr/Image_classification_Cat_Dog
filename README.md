# 🐱🐶 Cat vs Dog Image Classification using CNN

## 📌 Overview

This project implements a **Deep Learning based Image Classification System** that can accurately distinguish between **Cat** and **Dog** images using a **Convolutional Neural Network (CNN)**.  
It also includes a **Streamlit Web Application** that allows users to upload an image and receive real-time predictions.

The project demonstrates the complete **Machine Learning lifecycle** — from data preprocessing and model training to deployment.

---

## 🚀 Features

- Binary Image Classification (Cat vs Dog)
- CNN Model built using TensorFlow/Keras
- Data Augmentation & Preprocessing
- Model Evaluation with Accuracy & Loss Metrics

## 🧠 Model Architecture

- Convolutional Layers (Feature Extraction)
- MaxPooling Layers (Dimensionality Reduction)
- Flatten Layer
- Dense Fully Connected Layers
- Dropout Layer (Overfitting Prevention)
- Output Layer with **Sigmoid Activation**
